# Руководство по сборке ISO-образа AeroOS

Это руководство содержит пошаговые инструкции по компиляции собственного установочного ISO-образа AeroOS.

---

## Способ 1: Сборка прямо из Windows (через Docker Desktop)

Это самый простой способ для пользователей Windows: вам не нужно вручную ставить виртуальную машину с Linux.

### Требования:
1. Установленный и запущенный **Docker Desktop** для Windows.
2. Не менее 25 ГБ свободного места на SSD.

### Пошаговый запуск:
1. Откройте **PowerShell от имени Администратора**.
2. Перейдите в папку проекта:
   ```powershell
   cd "C:\Users\h6rnyx\Desktop\моя ОС"
   ```
3. Запустите скрипт сборки:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\build\build-in-docker.ps1
   ```
4. Скрипт автоматически:
   * Соберет сборочный контейнер на базе Fedora 40 с `lorax` и `livemedia-creator`.
   * Запустит генерацию образа с разметкой squashfs и пакетами.
   * Положит готовый файл `AeroOS-1.0-x86_64.iso` и хэш `.sha256` в папку `output\`.

---

## Способ 2: Сборка на физическом Linux / виртуальной машине Fedora

Если у вас есть установленная Fedora (на ноутбуке, сервере или в VirtualBox/VMware):

1. Установите сборочные инструменты:
   ```bash
   sudo dnf install -y lorax pykickstart git
   ```
2. Склонируйте или скопируйте папку проекта:
   ```bash
   cd ~/aero-os
   ```
3. Запустите сборщик с правами суперпользователя:
   ```bash
   sudo bash build/build-iso.sh
   ```
4. По завершении файл образа будет сохранен в `output/AeroOS-1.0-x86_64.iso`.

---

## Тестирование ISO перед установкой

### В VirtualBox / VMware:
* **Тип ОС:** Linux -> Fedora (64-bit)
* **Память:** 2048 МБ (2 ГБ) или 4096 МБ (4 ГБ) для проверки работы в целевых условиях.
* **Видеопамять:** 128 МБ (включить 3D-ускорение).
* **Контроллер:** EFI (для проверки Wayland и современного загрузчика).

### Быстрый запуск в QEMU (Linux / WSL2):
```bash
qemu-system-x86_64 \
    -m 2048 \
    -smp 2 \
    -enable-kvm \
    -cdrom output/AeroOS-1.0-x86_64.iso \
    -boot d \
    -vga virtio \
    -display gtk,gl=on
```

## Запись на USB-флешку

1. **Через Ventoy (Рекомендуется):**
   * Установите [Ventoy](https://www.ventoy.net) на флешку.
   * Просто скопируйте файл `AeroOS-1.0-x86_64.iso` в корень флешки.

2. **Через Rufus (Windows):**
   * Выберите вашу флешку и файл `AeroOS-1.0-x86_64.iso`.
   * Схема раздела: `GPT`
   * Целевая система: `UEFI (non CSM)`
   * При появлении запроса выберите режим **«Запись в режиме DD-образа»**.
