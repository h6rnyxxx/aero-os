# Руководство по кастомизации AeroOS

Этот документ описывает, как адаптировать дистрибутив под личные предпочтения: изменить внешний вид, добавить проприетарные драйверы или предустановить сторонние программы.

---

## 1. Добавление проприетарных драйверов NVIDIA

Для устройств с дискретными видеокартами NVIDIA GeForce откройте `kickstart/aero-core.ks` и раскомментируйте следующие пакеты в блоке `%packages`:

```kickstart
# Драйверы NVIDIA (из подключенного RPM Fusion Non-Free)
akmod-nvidia
xorg-x11-drv-nvidia-cuda
xorg-x11-drv-nvidia-power
```

---

## 2. Изменение предустановленного ПО

Список пакетов редактируется в `kickstart/aero-core.ks`:
* Чтобы добавить пакет: просто допишите его название в секции `%packages`.
  * Например, для добавления офисного пакета: `libreoffice-writer`, `libreoffice-calc`.
  * Для браузера Chrome: `google-chrome-stable` (потребуется добавить репозиторий Google Chrome).
* Чтобы удалить пакет из базовой установки: добавьте знак минуса перед именем пакета (например, `-dragonplayer`).

---

## 3. Настройка внешнего вида и цветовой темы

Все системные профили интерфейса хранятся в каталоге `configs/plasma/`:
1. **Цвета и акценты:** `configs/plasma/kdeglobals`
   * Параметр `AccentColor=0,120,212` задает акцентный синий цвет Windows 11 (#0078D4).
   * Если вам нравится темный изумруд или фиолетовый — измените эти RGB-значения.
2. **Панель задач и виджеты:** `configs/plasma/plasma-org.kde.plasma.desktop-appletsrc`
   * Чтобы изменить размер панели: отредактируйте `thickness=48` (например, на `42` для более компактного вида).
   * Чтобы вернуть классическое выравнивание иконок слева: удалите первый спейсер `plugin=org.kde.plasma.panelspacer`.
3. **Шрифты:**
   * По умолчанию используется `Inter` (современный гротеск).
   * Вы можете переключить на `Carlito` или `Selawik` в `kdeglobals`.

---

## 4. Добавление собственных обоев

1. Поместите изображение в формате PNG в `branding/wallpaper/`.
2. В файле `kickstart/aero-core.ks` добавьте команду копирования файла в каталог `/usr/share/wallpapers/AeroOS/contents/images/1920x1080.png`.
3. При первой загрузке KWin автоматически применит эти обои.
